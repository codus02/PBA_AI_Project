## 1. 라즈베리파이 5 첫 부팅 (한 번만)

### 1-1. microSD 카드에 OS 굽기 (메인 PC 에서)

1. https://www.raspberrypi.com/software/ 에서 **Raspberry Pi Imager** 다운로드 (Windows/Mac/Linux 다 있음)
2. 실행 → **CHOOSE OS** → "Raspberry Pi OS (64-bit)" 선택 (with Desktop 권장 — GUI 가 있어 처음엔 편함)
3. **CHOOSE STORAGE** → microSD 선택 (USB 어댑터로 PC 에 꽂아둠)
4. **NEXT** 누르기 전에 **EDIT SETTINGS** (또는 ⚙ 톱니 아이콘) 클릭
   - **Hostname**: 예를 들어 `cocktail-pi` (네트워크에서 찾을 이름)
   - **Username/password**: 새로 정할 계정 (예: `pi` / `cocktail123`)
   - **Wireless LAN**: 사용할 WiFi SSID + 비밀번호 (시연 장소 와이파이)
   - **Locale**: Asia/Seoul, ko_KR.UTF-8
   - **Services 탭** → **Enable SSH** ✓ (메인 PC 에서 원격 접속 가능)
5. Save → Yes (continue with image writing) → 5~10분 기다림
6. "Successfully written" 뜨면 microSD 빼서 Pi 에 꽂음

### 1-2. 첫 부팅 (Pi 에서)

1. microSD 카드 Pi 의 슬롯에 꽂기 (아래쪽)
2. 7인치 디스플레이가 있다면 Pi 와 연결 (DSI 케이블 / GPIO 4핀)
3. Pi 5 전원 어댑터 (PD45W 5V 5A) USB-C 로 연결
4. **빨간 LED + 초록 LED 깜빡임** = 부팅 정상
5. 화면에 부팅 로그 → 1~2분 후 데스크톱 등장
6. 처음엔 자동으로 wifi 연결 (Imager 에서 설정한 거)
7. 우측 상단에 wifi 아이콘 → 인터넷 OK 확인

### 1-3. 메인 PC 에서 SSH 접속 (디스플레이 없이도 작업 가능)

Pi 가 wifi 연결됐으면:

```bash
# Pi 의 IP 주소 알아내기 (옵션 1: 라우터 페이지)
# 옵션 2: Pi 에서 ifconfig 확인
ssh pi@cocktail-pi.local
# 또는
ssh pi@192.168.x.x
```

비밀번호 입력 → 접속 OK 면 Pi 의 터미널 사용 가능.
**이 시점부터는 메인 PC 에서 SSH 로 모든 작업 가능** (Pi 본체 모니터/키보드 없어도 됨).

## 4. GPIO 핀 매핑 + 배선

### 4-1. Pi 5 의 GPIO 핀 위치

```
Pi 5 의 40핀 헤더 (위에서 본 모습, 좌상단이 1번):

      3V3  [ 1] [ 2]  5V
GPIO  2    [ 3] [ 4]  5V
GPIO  3    [ 5] [ 6]  GND
GPIO  4    [ 7] [ 8]  GPIO 14
      GND  [ 9] [10]  GPIO 15
GPIO 17    [11] [12]  GPIO 18
GPIO 27    [13] [14]  GND
GPIO 22    [15] [16]  GPIO 23
      3V3 [17] [18]  GPIO 24
GPIO 10    [19] [20]  GND
GPIO  9    [21] [22]  GPIO 25
GPIO 11    [23] [24]  GPIO  8
      GND [25] [26]  GPIO  7
GPIO  0    [27] [28]  GPIO  1
GPIO  5    [29] [30]  GND
GPIO  6    [31] [32]  GPIO 12
GPIO 13    [33] [34]  GND
GPIO 19    [35] [36]  GPIO 16
GPIO 26    [37] [38]  GPIO 20
      GND [39] [40]  GPIO 21
```

### 4-2. MOSFET 보드 → 펌프 → 매핑 (8 채널)

```
펌프 채널 → BCM GPIO 번호 (Pi 핀)  → MOSFET 보드 IN 핀
   ch 0    → GPIO 17  (헤더 11번)  → MOSFET IN1
   ch 1    → GPIO 27  (헤더 13번)  → MOSFET IN2
   ch 2    → GPIO 22  (헤더 15번)  → MOSFET IN3
   ch 3    → GPIO 23  (헤더 16번)  → MOSFET IN4
   ch 4    → GPIO 24  (헤더 18번)  → MOSFET IN5
   ch 5    → GPIO 25  (헤더 22번)  → MOSFET IN6
   ch 6    → GPIO  5  (헤더 29번)  → MOSFET IN7
   ch 7    → GPIO  6  (헤더 31번)  → MOSFET IN8
```

이 매핑은 `scripts/pi_motor/cocktail_mixer.py` 의 `CHANNEL_TO_GPIO` 와 일치.

### 4-3. 배선 시퀀스 (전원 OFF 상태에서 작업!)

```
Pi 의 5V/GND, 12V 어댑터, MOSFET 보드 IN/OUT, 펌프 가 어떻게 연결되는지:

[Pi 5]                                          [12V 10A 어댑터]
  GPIO 17 ─────┐                                       ↓
  GPIO 27 ──┐  │                              [터미널 블록 V+]
  GPIO 22 ─┐│  │                                       ↓
  ...      ││  │                                  ┌────┴────┐
  GND ────┐││  │                                  │         │
          │││  │                                 12V       12V
          ▼▼▼  ▼                                  │         │
       ┌──────────────┐                            ↓         ↓
       │ 8채널 MOSFET │←───────────────GND ─→ [펌프1+]   [펌프2+]
       │   보드       │                            │         │
       │              │                          [펌프1-] [펌프2-]
       │ IN1~IN8 IN  │                            │         │
       │ OUT1~OUT8   ├──────────GND─────────→ [터미널 GND]
       └──────────────┘
              ↑
        OUT1~8 가 펌프의 (-) 또는 (+) 한쪽을 GND 에 연결/차단
        (MOSFET 의 low-side switching)

다이오드 (1N4007): 펌프 (+/-) 양쪽에 병렬로 — 펌프 OFF 시 역기전력 차단
                  (펌프 모터 코일이 OFF 될 때 발생하는 역전압이 MOSFET 깨먹음)
```

### 4-4. 처음 배선 시 안전 절차

1. **모든 전원 OFF** 상태에서 배선
2. **GND 공통화** 가 핵심 — Pi GND, MOSFET GND, 12V 어댑터 GND 모두 한 점에 모이게 (없으면 GPIO 신호 흔들려 펌프 오작동)
3. 첫 테스트는 **펌프 1개만** 연결. ch0 만 테스트 OK 면 나머지 추가.
4. 펌프 입출력 튜브: 입구는 1L 공병 안, 출구는 잔 위 (또는 호스 묶음)
5. 케이블타이로 정리 — 펌프가 떨림으로 빠지지 않게

## 5. 코드 — Fail-safe 설계

### 핵심 원칙
1. **하드웨어 없어도 작동** — 메인 PC 에서 개발/테스트 가능 (mock GPIO)
2. **MOCK_GPIO=1 환경변수** — Pi 에서도 강제 mock 모드 가능 (배선 전 dry-run)
3. **각 펌프 명령 try/except** — 한 채널 망가져도 다음 채널 진행
4. **emergency_stop** — 비상 시 모든 GPIO LOW
5. **시작/종료 시 cleanup** — pin floating 방지

전체 코드: [scripts/pi_motor/cocktail_mixer.py](../../scripts/pi_motor/cocktail_mixer.py)

### Fail-safe 코드 패턴

```python
try:
    import RPi.GPIO as GPIO
    HARDWARE_AVAILABLE = True
except (ImportError, RuntimeError):
    # Pi 가 아닌 환경 (메인 PC, Docker 등) → mock 자동 적용
    HARDWARE_AVAILABLE = False
    GPIO = MockGPIO()

if os.getenv("MOCK_GPIO", "0") in ("1", "true", "yes"):
    HARDWARE_AVAILABLE = False  # 강제 mock
```

→ Pi 에서든 메인 PC 에서든 같은 코드 실행 가능. 하드웨어 부재 시 로그만 찍고 계속 진행.

## 6. 첫 테스트 시퀀스 (배선 후 안전한 순서)

### 6-1. Mock 모드로 코드 검증 (하드웨어 연결 전)

Pi 에서:
```bash
cd ~/PBA_AI_Project  # 코드 옮긴 위치
MOCK_GPIO=1 python3 scripts/pi_motor/cocktail_mixer.py recipe_sample.json
# 로그에 "[mock GPIO] pin 17 → HIGH ... LOW" 찍히면 OK
```

### 6-2. LED 한 개로 GPIO 신호 검증

펌프 직접 연결 전, **GPIO 17 → 220Ω 저항 → LED → GND** 로 빛 깜빡이는지:
```bash
python3 -c "
import RPi.GPIO as GPIO
import time
GPIO.setmode(GPIO.BCM)
GPIO.setup(17, GPIO.OUT)
GPIO.output(17, GPIO.HIGH); time.sleep(1)
GPIO.output(17, GPIO.LOW)
GPIO.cleanup()
"
```
LED 1초 동안 빛나면 GPIO 정상.

### 6-3. MOSFET 단일 채널 테스트

배선 후, MOSFET IN1 에 GPIO 17 연결, OUT1 에 LED + 12V (부하 작은 거)
→ 위 코드 실행 → LED 깜빡 → MOSFET 정상.

### 6-4. 펌프 1개 테스트 (calibration)

```bash
# ch0 펌프만 30초 동안 ON → 받은 양 측정
python3 -c "
import sys; sys.path.insert(0, '/home/pi/PBA_AI_Project')
from scripts.pi_motor.cocktail_mixer import setup_gpio, run_pump, teardown_gpio
setup_gpio()
run_pump(0, 30000)  # 30초
teardown_gpio()
"
```
받은 물 측정 → flow_rate 계산 → 코드의 `DEFAULT_FLOW_RATE_ML_PER_SEC` 또는 `flow_rates_per_channel` 업데이트.

### 6-5. 8 채널 테스트

```bash
# 각 채널 1초씩
python3 -c "
import sys; sys.path.insert(0, '/home/pi/PBA_AI_Project')
from scripts.pi_motor.cocktail_mixer import setup_gpio, run_pump, teardown_gpio
import time
setup_gpio()
for ch in range(8):
    print(f'ch {ch}'); run_pump(ch, 1000); time.sleep(0.5)
teardown_gpio()
"
```

각 채널의 펌프가 1초씩 작동하면 모든 채널 OK.

## 7. 메인 서버 ↔ Pi 통신 (옵션)

데모 시 사용자 챗 → 메인 서버에서 추천 → Pi 가 자동으로 받아 제조하려면:

### 옵션 A: Pi 가 REST API 서버 (간단)
Pi 에서 작은 Flask 서버 실행:
```python
# pi_server.py
from flask import Flask, request, jsonify
from cocktail_mixer import setup_gpio, execute_recipe, teardown_gpio
app = Flask(__name__)

@app.route("/mix", methods=["POST"])
def mix():
    recipe = request.get_json()
    setup_gpio()
    try:
        result = execute_recipe(recipe)
    finally:
        teardown_gpio()
    return jsonify(result)

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```

메인 서버에서:
```python
import requests
requests.post("http://cocktail-pi.local:5000/mix", json=recipe)
```

## 9. 자주 막히는 데 + 해결법

| 증상 | 원인 / 해결 |
|---|---|
| Pi 부팅 안 됨 (LED 빨강만) | microSD 잘못 꽂음 / OS 잘못 구워짐 → 다시 굽기 |
| Wifi 연결 실패 | Imager 단계에서 SSID 오타 / 보안 방식 차이 → Pi 직접 설정 또는 유선 LAN |
| SSH 거부 | Imager 에서 SSH 활성화 안 함 → 한 번 부팅해서 sudo raspi-config 로 활성화 |
| GPIO permission denied | sudo 로 실행 또는 user 를 gpio 그룹에 추가 (`sudo usermod -aG gpio pi`) |
| 펌프 안 돔 | 1) GND 공통화 안 됨 2) MOSFET 신호 안 받음 (LED 테스트로 확인) 3) 펌프 자체 고장 |
| 펌프 멈춰있는데 GPIO 가 HIGH | MOSFET active-low 인 보드 가능성 → 코드 invert (HIGH↔LOW) |
| 동시 펌프 ON 시 GPIO 신호 떨림 | 12V 어댑터 부족 → 동시 채널 줄임 |
